# 💊 HealthBridge

HealthBridge is a Flutter-based mobile application that connects medicine and medical equipment donors with people and organizations in need. The platform aims to reduce medicine wastage while improving access to essential healthcare resources.

## 🚀 Features

- 👤 Secure user authentication
- 💊 Donate unused medicines
- 🏥 Request medicines and medical equipment
- 📋 Manage donation requests
- 🔔 Real-time notifications
- ☁️ Firebase backend integration

## 🛠️ Tech Stack

- Flutter
- Dart
- Firebase Authentication
- Cloud Firestore
- Firebase Cloud Messaging

## 📂 Project Structure

```
lib/              → Flutter source code
assets/           → Images & resources
functions/        → Firebase Cloud Functions
android/          → Android configuration
ios/              → iOS configuration
web/              → Web support
```

## 📌 Status

🚧 **Completed (Core Features)**

Future improvements include NGO integration, advanced verification, and enhanced search capabilities.

## 🎯 Objective

HealthBridge aims to bridge the gap between donors and recipients by creating a secure, user-friendly platform for medicine and medical equipment donation.
